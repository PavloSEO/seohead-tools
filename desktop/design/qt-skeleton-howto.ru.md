# Файл для Figma

`SEOHEAD — Qt skeleton.svg` — векторная отрисовка фактического PyQt5-каркаса. Импортируй SVG или перетащи его на страницу Figma как исходный визуальный ориентир. Это не native.fig и не завершённый дизайн продукта.

Исходный `../Untitled.fig` не изменён. Проверены контейнер/метаданные/сжатое сообщение: Document, Page1 и InternalOnlyCanvas; полноценные экранные слои через Figma-клиент не проверялись. Если есть исходная ссылка Figma, её можно использовать для точного разбора компонентов.

Дальнейшие правки рабочего дизайна должны оставаться согласованными с theme/tokens.json, theme.qss и Qt layouts, а не существовать только в макете.
