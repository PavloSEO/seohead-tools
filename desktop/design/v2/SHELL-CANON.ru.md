# Канон оболочки SEOHEAD Desktop · 3 режима

> Одна правда для всех досок канваса. Доска, которая не совпадает с этим файлом, — дефект,
> если она не названа в §7. Визуальная сверка — доска «Канон оболочки · 3 режима»
> (`ShellCanon.dc.html`, зона G). Проверка — скрипт аудита (`consistency/audit.py --canon`):
> 0 несоответствий на 09.10.2026.

Общие компоненты: `TopBar.dc.html` (шапка + вкладки) и `SideNav.dc.html` (навигация 200 px).
Доски оболочки подключают их через `dc-import` с пропсом `mode`; копировать шапку руками нельзя.

## 1. Режимы отображения

| Режим | `mode` | Где включается | Что видно |
|---|---|---|---|
| С агентом | `agent` (по умолчанию) | меню профиля → «С агентом» | всё: цели, входящие, методы, MCP |
| Простой | `simple` | меню профиля или клик по чипу «Простой режим» | те же проекты, сканы, сравнение, отчёты; без ИИ-функций |
| Краулер без проекта | `crawler` | пункт навигации «Краулер», меню профиля, меню чипа | то же окно: обычная навигация и профиль; меняется только шапка, пункты проекта неактивны |

Старый пропс `simple=true` продолжает работать и равен `mode="simple"`.

## 2. Шапка (`TopBar`)

Высота 52 px; у режимов проекта под ней строка вкладок 36 px (итого 88).

**(a) С агентом** — слева направо: свернуть навигацию · логотип SEOHEAD (→ Старт) ·
переключатель проекта «Мебельный магазин / shop.example.test · основной сайт» ·
переключатель скана «Скан №2 · r-0142 / 07.10.2026 14:20 · 1 314 URL · частичный» · пусто ·
**чип агента** · «Действия и переходы ⌘K» · обновить · «Новый скан» (primary).
Чип агента, пропс `agent`:

| `agent` | Текст | Стиль | Клик |
|---|---|---|---|
| `seen` (по умолчанию) | Агент · был 3 мин назад | `st-agent` | подключение агента |
| `online` | Агент · на связи | `st-run` | подключение агента |
| `off` | Агент · не подключён | `st-off` | Настройки · Агент |

**(b) Простой** — то же, но вместо чипа агента чип **«Простой режим ▾»**; клик открывает меню
«Отображение»: С агентом / Простой (✓) / Быстрый краул без проекта. На доске простого режима нет
ни одного агентского элемента: ни `smart_toy`, ни «Входящих», ни «Методов», ни «Заметки агенту».

**(c) Краулер без проекта** (`mode="crawler"`, высота 52, вкладок нет) — логотип ·
чип «Краулер · без проекта» (→ к проектам) · адрес цели (`target`, по умолчанию
`https://shop.example.test/`) · состояние (`crawlState`) · пусто · ⌘K · «Новый краул» ·
**«Сохранить как проект»** (primary). Переключателей проекта и скана нет. Это **не отдельное приложение**: слева тот же `SideNav mode="crawler"` с профилем «Павел · Краулер · без проекта · MCP вкл.», настройками и переключателем отображения. Доска настройки краула
(`Crawler`) рисует ту же шапку с редактируемым адресом и кнопками запуска — состав элементов тот же.

## 4. Вкладки рабочей области

Канонический набор и порядок, одинаковый в обоих режимах проекта:

1. «Работа · цель и задачи» (`work`; в простом режиме ведёт на Simple)
2. «URL · скан №2» (`url`) — **закреплена** (значок булавки вместо крестика)
3. «Сравнение №1 → №2» (`compare`)
4. «Проблемы · 4xx» (`issues`)
5. контекстная вкладка доски (`tab="none" label=… icon=…`) или «Новая вкладка» (`tab="new"`) — пятой, активной.

Справа: «+» (новая вкладка) и «Настроить вкладки и панели». Компактное окно показывает те же 4 вкладки иконками.

## 6. Строка состояния

Высота 26 px, фон `#F4F6FA`, есть на каждой доске оболочки (кроме полноэкранной справки — у неё своя).
Слева — сообщение доски (что показано, откуда данные, «Только чтение сохранённого запуска»).
Справа — служебный хвост. Если факт показан, он равен канону: «Проект «Мебельный магазин»»,
«Активных сканов: 1», «Ядро seohead 3.4», «Наблюдение: 12 с назад» (или «каждые 2 с» на досках скана),
команда ядра и id запуска (`findings-view · r-0142`). В простом режиме — «Простой режим · агент и MCP выключены».

## 7. Кому можно отличаться

| Доски | Почему | Что всё равно обязательно |
|---|---|---|
| Settings, Set* | отдельное окно настроек ⌘, | демо-данные §5, версии |
| ScanDialog, ScanList, Sc* | модальное окно «Новый скан» поверх оболочки, своя шапка окна | хост `shop.example.test` |
| Start, Onboarding | экран до выбора проекта: нет переключателей проекта/скана | чип агента «Агент · был 3 мин назад», логотип |
| Compact | окно 800×800: сокращённая шапка «Мебельный магазин · №2», чип «Агент · 3 мин», вкладки иконками | состав §2a и §4 |
| Menus, Modals, Shortcuts, Palette, TabSettings | галереи оверлеев поверх оболочки | подписи пунктов §3–4 |
| States*, Loading, ErrorsCore, Notify, Motion | галереи состояний: показывают стресс-случаи (1 000 000 URL, сканы №4/№5) и ошибки ядра | оболочка — общий TopBar/SideNav |
| CLI, Watch, Install | терминал и установщик, не окно приложения | демо-данные §5 |
| System, TopBar, SideNav, Colors, Library, Icons, Themes, Guide, Brand, ShellCanon | дизайн-система | — |
| Help, ReportPreview | полноэкранные документы без навигации | TopBar режима |
