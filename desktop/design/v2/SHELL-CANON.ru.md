# Канон оболочки SEOHEAD Desktop · 3 режима

> Одна правда для всех досок канваса. Доска, которая не совпадает с этим файлом, — дефект,
> если она не названа в §7. Визуальная сверка — доска «Канон оболочки · 3 режима»
> (`ShellCanon.dc.html`, зона G). Проверка — скрипт аудита (`consistency/audit.py --canon`):
> 0 несоответствий на 09.10.2026.

Общие компоненты: `TopBar.dc.html` (шапка + вкладки) и `SideNav.dc.html` (навигация 200 px).
Доски оболочки подключают их через `dc-import` с пропсом `mode`; копировать шапку руками нельзя.

## 1. Режимы отображения

| Режим | `mode` | Где включается | Что видно |
|---|---|---|---|
| С агентом | `agent` (по умолчанию) | меню профиля → «С агентом» | всё: цели, входящие, методы, MCP |
| Простой | `simple` | меню профиля или клик по чипу «Простой режим» | те же проекты, сканы, сравнение, отчёты; без ИИ-функций |
| Краулер без проекта | `crawler` | пункт навигации «Краулер», меню профиля, меню чипа | то же окно: обычная навигация и профиль; меняется только шапка, пункты проекта неактивны |

Старый пропс `simple=true` продолжает работать и равен `mode="simple"`.

## 8. Согласованность: термины, числа, статусы, действия

Проверяется `audit_consistency.py` (по отрисованным доскам). Код возврата аудита с `--canon` — 1 при любом
несоответствии вне §7/§7a.

**Термины.** скан (наш запуск; «обход» — только про поисковых роботов и описание режима), краул — только
«краул без проекта», перепроверка (не «повторная проверка», не «повторный скан»), задача (не «таск»),
проблема — проверка с находками, находка — строка внутри проблемы, исполнители — Программист / SEO / Контент,
встроенный краулер (не native crawler), HTML после рендеринга (не Rendered DOM / «Отрисованный JS»),
компьютер / телефон (окно просмотра рендера), Входящие — сообщения агенту; у ссылок — «входящие ссылки».

**Подписи действий.** «Новый скан» (play_arrow → ScanDialog), «Перепроверить выбранные» (replay, ⌘R),
«Экспорт» (download), «Экспорт и отчёты» (ios_share → ProjExport), «Новый проект» (create_new_folder),
«Диагностика…» и «Проверить все» (stethoscope), «Сбросить…» (restart_alt), «Импорт» (upload_file),
«Сканы» (history), «Новая вкладка» (add; у самой вкладки — tab), «Действия и переходы» (⌘K → Palette).
Малые кнопки — класс `.btn.sm` (28 px, 12 px), а не ручные `height`/`font-size`.

**Горячие клавиши (одна раскладка в Shortcuts, SetKeys, Menus, Palette).** ⌘K действия и переходы · ⌘N новый
скан · ⌘P пауза / продолжить · ⌘. остановить скан · ⌘R перепроверить выбранные · ⌘T новая вкладка · ⌘W закрыть
вкладку · ⌘, настройки · ⌘C копировать URL · ⌘⇧C колонки · ⌘J задача из выбранных · ⌘1 Работа · ⌘2 Сканы ·
⌘3 URL · ⌘4 Проблемы · F1 справка.

**Цвета.** Процессы и задачи — классы `st-*` с доски Colors: Новая st-new · В работе / Идёт st-run ·
Ждёт перепроверки st-queue · Подтверждено st-verified · Частичный st-partial · Устарело st-stale ·
Прерван st-int · Черновик st-draft · Агент st-agent. Значения данных — `ok / info / warn / err / mut`:
HTTP 2xx ok · 3xx info · 4xx warn · 5xx err; «Индексируется» ok, «Редирект» info.

**Формат.** Тысячи через пробел (`1 314`), десятичная запятая (`0,3 МБ`, `4,5:1`), даты `ДД.ММ.ГГГГ`
