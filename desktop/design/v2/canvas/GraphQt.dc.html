Граф ссылок · как сделать в Qt
Спецификация для реализации в desktop/ · PyQt5, без WebView · данные только из ядра seohead

databaseДанные

  • Рёбра — таблица links скана: источник, цель, анкор, nofollow, position.
  • Фильтр «шапка / подвал / контент» = условие по position прямо в SQL, не в Python.
  • Узлы — pages: код, глубина, индексация, входящие.
  • Нужна команда ядра, отдающая граф порциями: узлы и рёбра по разделу или вокруг URL, с агрегатом «раздел → раздел».
seohead scan-graph SCAN \ --positions content \ --section /catalog/kuhni/ \ --around URL --depth 2 \ --aggregate sections --json

Такой команды пока нет — оформить как core-gap (рядом с #924 «ссылки по URL»).

memoryОтрисовка

  • QGraphicsView + QGraphicsScene, узел — лёгкий QGraphicsItem с paint(), без виджета на узел.
  • Раскладка (force / radial / tree) считается в рабочем потоке, в UI приходят готовые координаты.
  • Координаты кэшируются в папке проекта на скан: второй раз граф открывается мгновенно.
  • Уровни детализации: подписи только при приближении и у крупных узлов; рёбра тоньше при отдалении.
  • Наведение подсвечивает соседей; клик открывает карточку узла.
  • Цвета — только токены темы (светлая, тёмная, контраст).

speedМасштаб и бюджеты

  • До 5 000 узлов — полный граф.
  • Больше 5 000 — разделы сворачиваются в кластер-узлы, «раскрыть раздел» подгружает его порцию.
  • 1 000 000 URL: на экране не больше 5 000 узлов и 20 000 рёбер, полная выборка в память не грузится.
  • Открытие графа ≤ 2 с с кэшем раскладки, ≤ 10 с без него (в фоне, с прогрессом и отменой).
  • Сравнение №1 → №2: разница рёбер считается в ядре, приложение рисует только итог.
