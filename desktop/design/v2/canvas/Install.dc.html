Программы
Один комплект: приложение, совместимое ядро и CLI seohead одной версии. Python и пакеты не нужны. Windows — установщик .exe, Linux — AppImage; на них то же предложение установить CLI.
Где что окажется
Приложение
/Applications/SEOHEAD Desktop.app
CLI
/usr/local/bin/seohead
Состояние MCP
~/Library/…/SEOHEAD/mcp.json
Первый запуск

Как вы будете работать?

Отображение меняется в любой момент в меню профиля слева внизу. В простом режиме шаг MCP пропускается.

Командная строка

Установить seohead в командную строку/usr/local/bin
~ $ seohead --version
seohead 3.4.0 · desktop 0.9.0
Потребуется пароль администратора macOS. Удалить: Настройки → Ядро → «Убрать из командной строки».
