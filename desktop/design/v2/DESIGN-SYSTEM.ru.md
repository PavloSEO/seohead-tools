## 1. Принципы

1. **Таблица — главный герой.** Всё, что не таблица, занимает минимум места и сворачивается.
2. **Честные состояния.** «Нет данных» ≠ «0». «Сохранено» ≠ «агент работает». «Отчёт сформирован» ≠ «проблема исправлена». У каждого состояния — иконка + текст, не только цвет.
3. **В реальном режиме не бывает слова «Демо».** Демо-фикстуры существуют только в `--capture`, тестах и галерее компонентов.
4. **Одна шапка.** Проект → сайт → запуск выбираются в одной строке 52 px. Никаких второй и третьей полос.
5. **Каждое пустое состояние даёт следующий шаг** (кнопка действия), а не голый заголовок таблицы.
6. **Русский интерфейс целиком.** Никаких Cancel/OK, `limits.max_depth`, «HTTP headers». Технические ключи — только в тултипе/деталях.
7. **Иконки — только Material Symbols Outlined** (opsz 20/24, wght 400, FILL 0). Если нужной нет — рисуем свою в той же сетке 24 px, обводка 2 px, скругления как у Symbols.

### Сетка, размеры, плотность

- Отступы: 4 · 8 · 12 · 16 · 20 · 24 · 32. Внутри панели 16, у края экрана 20.
- Радиусы: 4 поле-чекбокс · 8 кнопка/поле/пункт · 12 карточка/меню/панель · 14 чип/пилюля · 16 диалог.
- Строки таблиц: 28 плотно · **32 стандарт** · 40 просторно. Заголовок таблицы 34.
- Кнопки 32 (в диалоге 36). Иконка-кнопка 32×32, иконка 20 (в плотных местах 16–18).
- Каркас: шапка **52** · полоса вкладок рабочей области **36** · навигация **200** (rail **64** при ширине < 1100) · правая сводка **296** · нижние детали **≈320** (сплиттер) · статус-бар **26**.
- **Минимальное окно 800×800.** При < 1100: навигация → rail с подписями 10 px; сводка справа уходит вкладкой «Сводка» в нижнюю панель (канвас: «Компактное окно 800×800»).

### Тени и движение

- Рабочее пространство плоское. Тень только у меню (`0 8 24 rgba(10,20,40,.16)`) и диалогов (`0 12 40 rgba(10,20,40,.22)`), в Qt — `QGraphicsDropShadowEffect` только на top-level popup/dialog.
- Hover: смена фона без задержки (QSS). Раскрытие панелей/аккордеона, переключение режима «развернуть таблицу» — 120 мс `QPropertyAnimation` OutCubic. «Уменьшить движение» → 0 мс.
- Никаких бесконечных спиннеров на устаревшем статусе. Живой статус — `progress_activity` + возраст наблюдения текстом.

## 3. Компоненты: QSS-селекторы, состояния, поведение

Варианты задаются **dynamic properties**, не отдельными stylesheet-строками в экранах. После смены свойства — `style().unpolish(w); style().polish(w)` только у этого виджета.

| Компонент | Qt | Свойства | Состояния |
|---|---|---|---|
| Кнопка | `QPushButton` | `role=primary\|secondary\|tonal\|text\|danger`, `size=md\|lg\|pill` | normal/hover/pressed/focus (2 px `#1565C0` outline, offset 2)/disabled |
| Иконка-кнопка | `QToolButton` | `role=icon` | + `checked` (фон `selected`) · обязательно `accessibleName` + tooltip |
| Бейдж | `QLabel` | `badge=ok\|info\|warn\|err\|mut\|goal` | всегда иконка 16 + текст |
| Чип фильтра | `QWidget`+`QToolButton ×` | `chip=filter` | крестик удаляет условие из реального запроса |
| Пилюля группы | `QToolButton` checkable | `pill=group` | checked = `selected`/`on_selected`; счётчик справа серым |
| Вкладки раздела | `QTabBar` | `tabs=underline` | активная: текст primary + линия 2 px; счётчик 11 px; при переполнении — стрелки + меню «все вкладки», **без обрезки текста** |
| Вкладки рабочей области | `QTabBar` (свой) | `tabs=workspace` | активная — белая «карточка» над полосой; иконка раздела; × на hover; ПКМ: новая/переименовать/закрепить/дублировать/в новом окне/закрыть/закрыть остальные; «+» открывает экран «Новая вкладка» |
| Навигация | `QListView` + delegate | `nav=item\|section` | группы «Данные», «Результат»; счётчики; активный — `selected`; rail-режим |
| Таблица | `QTableView` + `QAbstractTableModel` + delegate | — | чередование `#FAFBFC`, hover `#F5F8FD`, выбор `selected` + 2 px рамка фокуса; HTTP и индексация рисуются бейджами **делегатом** (не виджетом на ячейку); числа вправо; URL — хост серым + путь, middle-elide, полный в tooltip |
| Ключ–значение | `QFormLayout` / `QGridLayout` | `kv=row` | ключ 12 серый, значение 13; разделитель `#EEF0F3`; «Нет данных» курсивом |
| Баннер | `QFrame` | `note=warn\|info\|error\|success` | иконка + жирная первая фраза + действие кнопкой справа |
| Поле | `QLineEdit` | `invalid=true` | hover рамка темнее; focus 2 px primary; ошибка 2 px error + текст ошибки под полем; read-only — без рамки фокуса |
| Переключатель | `QCheckBox` | `switch=true` | 36×20, рисуется QSS-индикатором |
| Сегмент | группа `QToolButton` | `segmented=true` | выбранный — белый с тенью 1 px на `raised` |
| Карточка-выбор | `QToolButton` checkable | `card=choice` | выбранная: 2 px primary, фон `#F3F8FF` (источник скана) |
| KPI | `QFrame` | `kpi=true` | подпись 12, число 22/500, было зачёркнуто, дельта с иконкой тренда |
| Сплиттер | `QSplitter` handle | — | 7 px, «ручка» 32×3 по центру, hover primary; двойной клик — размер по умолчанию |
| Меню | `QMenu` | — | радиус 12, пункт 34, шорткат справа серым; на macOS — нативное меню приложения сохранить |
| Диалог | `QDialog` | — | радиус 16, шапка 60–64 с иконкой и подзаголовком, футер: слева подсказка/ошибка, справа «Отмена» (text) → основная (primary). Порядок кнопок одинаковый во всех диалогах |
| Статус-бар | `QStatusBar` | — | 26 px, 11 px, слева режим/возраст наблюдения, справа ядро и ID |

## 5. Иконка приложения и бренд

- Знак: скруглённый квадрат `#1565C0` (радиус ≈ 23 % стороны) + белая лупа (кольцо + ручка под 45°). На 64 px и больше внутри линзы две «строки отчёта». На 32 и 16 px — только лупа.
- Экспорт: исходник SVG в `assets/brand/`, `.icns` (16…1024 @1x/@2x), `.ico` (16, 24, 32, 48, 64, 256), PNG для Linux (48, 128, 256, 512). Канвас — лист «Токены и компоненты».
- Словесный знак: «SEOHEAD» Roboto 700, трекинг +0.6 px. В шапке — знак 24 + слово.
- Без лягушки, буквы G и эмодзи.

## 6. Что из топ-15 дефектов закрывает эта система

| Дефект текущего приложения | Решение |
|---|---|
| «Демо» в реальном режиме | правило 3; демо-провайдер только в capture/тестах |
| противоречивые состояния, «Новый скан» без проекта | кнопки недоступны с причиной в tooltip, пустые состояния с действием |
| 15 вкладок «Проекта» дублируют навигацию | вкладки «Проекта» убрать; разделы — только в навигации |
| обрезанные вкладки | QTabBar с прокруткой и меню «все вкладки», настройка вкладок |
| английский UI | словарь `translations.py`, кнопки диалогов через `QDialogButtonBox` с русскими подписями |
| чужеродный диалог параметров | единый каркас диалога (§3) |
| таблицы на 800 px | компактная раскладка, тонкий скроллбар, колонки по приоритету |
| разнобой кнопок | 5 ролей кнопок, один QSS |
| «Неизвестно», «Новая вкладка» | вкладка получает имя раздела и объекта |
| пустота на широком экране | KPI + таблица + детали, без центрированной колонки |
| обрезка «Индексирует…» | бейджи фиксированной ширины колонки 150 |
| сырые JSON и пути | «Диагностика» — в деталях под спойлером; путь — только в tooltip |
| неочевидные состояния | §3: disabled-стили, read-only без фокуса, ошибка у поля |
| навигация на 800 px | rail 64 с подписями, автосворачивание по ширине всегда |
