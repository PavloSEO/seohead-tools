## Решения владельца (не переспрашивать)
- Два отображения: **«С агентом»** и **«Простой»**. В простом — проекты, сканы, сравнение, перепроверка и отчёты без ИИ-функций. Пустых панелей агента там нет. Переключение — в меню профиля слева внизу.
- Режим «Краулер» — настоящий, без проекта, работает в обоих отображениях. В ядро нужно добавить журнал и лимит скорости без проекта.
- MCP: приложение само прописывает конфиги агентов **только после явного диалога-разрешения** (лист «Все модалки → Разрешить запись MCP»), с бэкапами. Единое состояние для приложения и CLI: `seohead mcp status|enable|disable`.
- Установщик — для себя, сборка из репозитория. macOS: `.pkg` кладёт приложение и обёртку `seohead` в `/usr/local/bin`. Для DMG: при первом запуске пункт «Установить командную строку». Подпись и нотаризация не нужны.
- Терминал: улучшить существующие `seohead watch` и `seohead tui` по листу «seohead watch».
- Логотип утверждён: серебристая лупа, фактурная паутина, чёрная вдова (`desktop/design/v2/brand/seohead-logo.svg`, квадрат — `seohead-logo-square.svg`, мелкий знак — `src/seohead_desktop/assets/app/seohead-small.svg`). Он уже стоит на GitHub, сайте и в README. Иконки приложения пересобрать родным Qt (`scripts/render_app_icon.py` в `.venv-desktop`) — сейчас они отрисованы Chromium.
