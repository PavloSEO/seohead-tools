# Разрыв между README и кодом приложения

Внутренний учёт. README (корень репозитория) описывает SEOHEAD Desktop в финальном виде по
канвасу design v2 — решение владельца 10.10.2026. Здесь — что из показанного уже есть в коде
`desktop/src/seohead_desktop` (ветка `feat/desktop-dir` на 10.10.2026) и каким шагом
[ROADMAP](../../ROADMAP.md) закрывается остальное. Оценка по ROADMAP и беглой сверке кода;
перед закрытием строки — проверка на `examples/qa-site`.
