# Подготовка SEOHEAD Desktop

Открой `Приложение.app` — собранный нативный каркас для текущего Mac. `Исходники приложения` ведёт к рабочему проекту в Work/tools/seohead-desktop; окружение и библиотеки находятся там же. Исходное ТЗ и Untitled.fig сохранены.

Работают: QSS/токены бренда, таблица демо-URL, поиск/сортировка, инспектор/вкладки, панели, preview без запуска скана. CLI-адаптер читает metadata существующего проекта в фоне; реальные URL/задачи/запуск сканов ещё не подключены.

Проверено на macOS arm64: сборка и нативный запуск, поиск через accessibility,4Qtтеста, чтение metadata ядра без скана. Windows/Linux ещё не проверялись. Демо — пять синтетических записей, не результат краула.

В папке Figma — SVG фактической Qt-отрисовки для импорта. Нативный.fig не редактировался: приложение Figma недоступно инструментам. Документы и код не содержат Electron/QtWebEngine UI. Большие сканы и остальные сценарии реализуются следующими этапами по ТЗ.
