- `check_sample` in `seohead/checks/custom_extract.py` runs CSS, XPath and regex extractors against one saved HTML document, without a scan or a network request. Each result carries its values and a `reason` for an empty outcome (`no_match`, `empty_html` or `budget_exceeded`), so an empty answer is never presented as a clean result (#1059). It is a core call only; no CLI or MCP tool is registered yet, and fetching a live URL is deliberately not included.
