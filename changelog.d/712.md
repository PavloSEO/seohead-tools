- `crawl-site` scan artifacts now stamp `finished_at` and a `finished` lifecycle once every
  accepted frontier row reaches a terminal state, including runs whose retained evidence is
  partial: `crawl_partial` already names omitted observations, so a drained queue no longer
  reads as an interrupted capture in `scan-status`, `scan-list`, or history (#712). An
  explicitly stopped run -- aborted before it accepted work, cancelled, or halted by the
  error circuit -- keeps `interrupted` and its recorded reason even after the queue drains,
  including through `resume_or_finalize`, so stop paths never receive a false finished
  timestamp.
