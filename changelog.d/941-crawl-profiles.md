- crawl-site profiles (#941): `--save-profile NAME --config FILE` stores a validated crawler config as a named profile (refused when it carries credential headers); `--profile NAME` crawls with it, and `--set` still applies on top. Profiles live in `~/.config/seohead/crawl-profiles` or the directory named by `SEOHEAD_CRAWL_PROFILES`. Listing and deleting profiles are not in this slice.
