- Новая команда `scan-structured-blocks` (CLI) и MCP-инструмент `seo_scan_structured_blocks`: по одному сохранённому URL описывает каждый JSON-LD блок (строка в источнике, состояние `valid` / `errors` / `warnings` / `parse_error`, типы, плоский список свойств, ограниченный исходный JSON и ошибки графа Schema.org). Работает офлайн, только по сохранённому полному телу страницы; не сетевые запросы и не изменения артефакта.
