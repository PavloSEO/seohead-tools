- New command `scan-structured-blocks` (CLI) and MCP tool `seo_scan_structured_blocks`: for one retained URL, describes each JSON-LD block (its source line, status `valid` / `errors` / `warnings` / `parse_error`, types, a flat list of properties, bounded source JSON, and Schema.org graph errors). Works offline on the retained full page body only; no network requests and no artifact changes.
