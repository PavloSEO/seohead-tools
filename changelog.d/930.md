- Redirect and canonical chain hops record each hop's status, next Location (redirects) and response time, so a URL's chain reads from stored evidence without another request (#930).
- Redirect loops in per-URL chains end with a marker step (`{"url": ..., "loop": true}`) that is not fetched again, so the repeated URL is visible in stored evidence; `final_url` still points at the last fetched hop (#930).
