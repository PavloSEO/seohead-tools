- `scan-url-query` and its MCP tool accept an optional `facets` argument (a list of group ids, or `all`) that returns per-group counts (`status_2xx`–`5xx`, `title_missing`, `canonical_missing`, `directives_noindex`/`nofollow`, `with_outlinks`) over the same filters in one pass. Groups that need a projection (internal/external, sitemap, title duplicate/length, canonical self/other) are not included yet.
