- Align the legacy `sources.gsc` block in `sources-doctor` with `provider_status.gsc`: `ready`
  and the new `components` field now come from the same credential components (OAuth bearer,
  durable grant, or service account) instead of only the bearer file, so a configured service
  account no longer reads as "GSC is not set up". The service-account component now validates
  the JSON document itself (private regular file, bounded size, `service_account` type, the
  exact Google token URI, and required fields) and both doctor blocks report a safe
  `service_account_status` enum (`missing`, `unsafe_file`, `malformed_json`,
  `unsupported_shape`, or `configured_unverified`), so a malformed file stays distinguishable
  from a configured-but-unverified one without exposing its contents.
