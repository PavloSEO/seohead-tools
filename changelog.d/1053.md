- DOM size checks (`DOM_TOO_DEEP`, `DOM_TOO_MANY_NODES`) now measure each page from the body a native `crawl-site` run retained in its scan store, instead of skipping by name on every native run. A page whose body was not kept (`storage.body_mode=off` or over `storage.max_body_bytes`) is skipped with that real reason, and partial retention keeps the coverage ratio. The near-duplicate fallback still needs HTML stored to disk.
