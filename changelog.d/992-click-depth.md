- `scan-url-query` returns `click_depth`, the shortest internal link path from the scan's start page, as a column, filter and sort key. Pages no stored link reaches are `NULL` (orphans). `crawl_depth` is unchanged and remains the frontier depth, which is 0 for every sitemap-seeded URL. A scan that did not retain its links fails with `reason_code: click_depth_unavailable` instead of reporting a false `NULL`. The value is recomputed per query from the `links` table; persisting it as an indexed column at scan finish is still open because it needs a schema-version decision (#992).
