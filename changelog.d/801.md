- New `semantic-inputs` command (`seo_semantic_inputs` over MCP) builds the
  reproducible normalized-input manifest the semantic-similarity work will
  consume: per document it records the retained body hash, the exact decoded
  input hash, the normalized output hash, the content-area strategy, and
  language evidence (the page's own `<html lang>` plus letter-script shares) —
  never the normalized text itself. `--scan` streams retained complete bodies
  offline under the crawl's recorded content-area config with no refetch, and
  a missing or partial body stays an explicit omission rather than a clean
  empty result (#801).
